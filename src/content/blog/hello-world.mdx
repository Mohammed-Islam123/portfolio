Every backend engineer keeps a notebook. Most of them live in `/tmp` and
die with the laptop. This one lives here — notes from building systems
that move bytes for a living.

## what you'll find here

Three kinds of posts, roughly:

- **Decisions** — why a protocol, a data path, or a trade-off went the
  way it did. The reasoning is the interesting part, not the code.
- **Failures** — the 3am pages and the boring paths that fixed them.
- **Habits** — the small tools and checks that keep the first two rare.

```csharp
// exactly-once, the boring way: an idempotency key + a unique index
public async Task<ConsumeResult> ConsumeAsync(OutboxRow row, CancellationToken ct)
{
    var existing = await _readStore.FindAsync(row.IdempotencyKey, ct);
    if (existing is not null)
        return ConsumeResult.AlreadyApplied; // redelivery — no-op

    await _readStore.ApplyAsync(row.Deserialize(), ct);
    return ConsumeResult.Applied;
}
```
